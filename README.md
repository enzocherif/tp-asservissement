# TP Asservissement — SYSMER 3A (SeaTech)

Synthèse de correcteurs sur une fonction de transfert : régulateur PI et correction à avance de phase.
Analyse par diagrammes de Bode et de Black-Nichols, marges de gain et de phase, réponses indicielles.

- `ftbf.m` : script principal (fonctions de transfert, correcteurs, tracés)
- `ftbff.slx` : modèle Simulink (R2024b)
- `Syst_detat.m` : représentation d'état
- `figures/` : diagrammes et réponses obtenues
